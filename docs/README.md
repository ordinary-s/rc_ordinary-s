# 项目文档导航

本项目是 **Go + MySQL/InnoDB + Apache RocketMQ + Transactional Outbox** 的单实例 HTTP 通知 MVP。任务受理、发布责任、HTTP 尝试和人工结论保存在 MySQL；Go 发布器补偿未完成的消息发布，RocketMQ 提供消息交付与执行异常的原生重试。

一条任务最多三次 HTTP **业务尝试，包含首次**。`DELIVERED`、`FAILED`、`FAST_FAILED`、`EXPIRED`、`UNCERTAIN` 可靠保存后均结束消费；机构快速失败开关关闭不会复活旧终态。详细规则与实现限制以完整设计和实现核对表为准。
